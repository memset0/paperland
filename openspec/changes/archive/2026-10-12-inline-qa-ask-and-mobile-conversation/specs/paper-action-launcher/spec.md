## REMOVED Requirements

### Requirement: Desktop top-right function list
**Reason**: Its only function, "Ask", is replaced by the inline question box and the conversation view.
**Migration**: Ask from the box under the User Q&A header, or in the conversation view.

### Requirement: Mobile circular floating action button
**Reason**: The mobile bottom bar's Ask item is a section (the conversation view), not a launcher action.
**Migration**: Use the Ask section of the mobile bottom bar.

### Requirement: Function order follows the page's function order, extensible
**Reason**: The launcher is removed.
**Migration**: None.

### Requirement: Launching the QA function opens the QA floating window
**Reason**: The floating question window is removed.
**Migration**: Use the inline question box or the conversation view.
