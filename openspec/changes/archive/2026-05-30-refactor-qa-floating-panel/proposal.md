## Why

给 Agent 提问的输入框（`QAInput`）目前被**常驻钉死**在论文详情页：宽屏时绝对定位在左侧 PDF 栏底部、窄屏时 `fixed` 在视口底部。它始终占据视野、遮挡 PDF 阅读区，且把"提问"这一个功能硬编码在固定位置，无法承载后续会陆续加入的其他功能。我们希望把它改造成像"笔记"那样**按需点开的浮动窗口**，并为论文详情页提供一个可扩展、按页面功能顺序排列的功能入口。

## What Changes

- **提问框从常驻改为按需浮动面板**：移除宽屏左侧栏底部、窄屏视口底部的常驻 `QAInput`；改为点击功能入口后才弹出浮动面板。面板**就是 `QAInput` 卡片本身（单层）**，不套额外窗口外壳/标题栏，避免"窗口套卡片"的双层边框；外圈即卡片自身边框，保持其原有大小。
- **面板支持拖动**：弹出后可通过**面板右下角的拖动手柄**移动位置（桌面端），方便挪开以免遮挡；输入框自身不再可缩放。
- **浮窗默认位置/大小每次重新计算、不记忆**：与"笔记"窗口跟随上次尺寸的逻辑不同，提问浮窗每次弹出都回到默认位置和大小。
  - 双栏页面：沿用当前的计算规则，默认贴在**左下角**、宽度等于左侧（PDF）栏宽度（"占据下方一半"为口语表述，按现有规则计算，不是字面意义的一半）。
  - 单栏页面：占据**下方完整横向空间**（全宽）。
  - 移动端：与"笔记"窗口一致，以**全屏浮层**形式打开。
- **新增功能入口（可扩展、按页面功能顺序排列）**：
  - 电脑端：在论文详情页**右上角**直接平铺列出所有功能按钮（**不是下拉菜单**），点击"提问"即打开提问浮窗。当前仅有"提问"一个功能。
  - 手机端：新增一个**圆形悬浮按钮（FAB）**，点击后弹出功能列表（含当前"提问"及后续新增功能）。
  - 功能顺序与论文详情页已有功能区块的顺序一致（引用 → 笔记 → 提问），入口按此顺序排列；当前仅"提问"一项，入口设计为可扩展。
- **面板内控件布局优化**（提问框内容本身不重新设计，仅以下布局调整）：
  - 顶部一行自左至右为：提交按钮（左端）→ 模型选择 → 关闭按钮（右上角，即原提交按钮位置）。
  - 输入框移到顶部行下方、占据完整横向宽度，且自身去掉缩放手柄（移动改由面板右下角拖动手柄完成）。
  - 提交按钮不再只显示图标，改为图标 + "Submit" 文字。

## Capabilities

### New Capabilities
- `paper-action-launcher`: 论文详情页的功能入口——电脑端右上角平铺的功能按钮列表、移动端圆形悬浮按钮（FAB）展开的功能列表；可扩展、按页面功能区块顺序排列，当前仅暴露"提问"功能并负责打开提问浮窗。

### Modified Capabilities
- `qa-input-floating`: 提问框的呈现方式从"常驻钉底（移动端 fixed 底部 / 桌面端 sticky）"改为"按需弹出、可拖动、默认位置/大小每次重算且不记忆的浮动窗口"；同时调整提问表单内部布局（提交按钮移到模型选择同一行、加 "Submit" 文字、输入框占满宽度）。

## Impact

- **前端组件**
  - `packages/frontend/src/components/QAInput.vue`：改造为按需浮动面板（卡片自身即面板：桌面 `fixed` 底部锚定 + 几何、移动端全屏）；控件布局调整（提交左、关闭右上、右下角拖动手柄、输入框全宽且 `resize-none`）。提交/模型选择逻辑不变。
  - 新增 `composables/useQAWindow.ts`（开关状态 + 底部锚定的默认几何 `left/bottom/width`，不记忆/不持久化）。
  - 新增 `paper-action-launcher` 入口组件（电脑端右上角功能列表 + 移动端圆形 FAB）。
  - `packages/frontend/src/views/PaperDetail.vue`：移除宽屏左栏底部与窄屏底部的常驻 `QAInput`；header 右侧挂功能入口、页面挂浮动面板；向面板提供按当前布局（双栏/单栏）计算的默认几何。
- **不在本次范围**：`QAPanelNav`（右侧滚动导航点条）、`QAList`（答案展示）、提问/模型选择的业务逻辑、后端 API 均保持不变。
- **文档**：更新 `docs/frontend-architecture.md` 中提问框/详情页布局相关描述。
